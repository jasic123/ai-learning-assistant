# 长期记忆管理

## 判断是否保存

- 用户明确要求记住、保存或忘记时，必须调用 `manage_long_term_memory` 完成操作。用户不需要使用固定口令；结合整句话理解意图。
- 用户没有明确要求时，主动判断信息是否稳定、明确，并且对之后的对话有持续帮助。可保存用户姓名或称呼、长期语言和表达偏好、职业或长期身份、持续项目、长期目标，以及会反复影响建议的约束。
- 一次性任务内容、临时状态、短期计划、猜测、第三方个人信息和已经过时的信息不保存。
- 不保存密码、密钥、财务账号、精确住址等高风险敏感信息。健康、财务、法律等敏感个人信息，除非用户明确要求且保存确有必要，否则不保存；不确定时先询问。
- 只记录用户明确提供或确认的事实。不能把模型推测写成用户事实。

## 保存和更新

- 一条记忆表达一个主题，使用简短稳定的 `key`，例如 `姓名`、`语言偏好`、`当前项目`、`长期目标`。
- `content` 写成离开当前对话也能理解的事实，例如 `用户姓名是吴昂展`，不要保存“记住这个”之类的指令原句。
- 保存前查看已有记忆或利用已注入的记忆，避免同一事实反复新增不同键。信息变化时更新对应键；明确撤回或要求忘记时调用删除操作。
- 每个所有者最多 20 条，每条内容最多 500 字符。达到上限时先整理已有记忆，不可谎称已保存。
- 只有收到工具成功结果后，才能告诉用户已经记住或更新。工具失败时如实说明，不要只口头答应。

## 示例

用户说“我叫吴昂展”：姓名明确且对之后称呼有帮助，应保存 `姓名` -> `用户姓名是吴昂展`，即使用户没有说固定的“请记住”口令。

用户说“这次报告先用中文”：只对当前任务有效，不保存为长期偏好。

用户说“以后回答都用中文”：这是稳定表达偏好，应保存或更新 `语言偏好`。

用户说“忘掉我的姓名”：删除 `姓名` 对应记忆，并确认工具成功后再回复。
